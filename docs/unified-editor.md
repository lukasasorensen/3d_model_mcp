# Unified 3D editor

The [THE-75](https://linear.app/theoryfoundry/issue/THE-75/unify-object-editing-in-the-main-3d-view) and [THE-76](https://linear.app/theoryfoundry/issue/THE-76/move-parameter-controls-into-a-floating-right-hand-panel) mockup uses Canva as a reference for the selection toolbar and floating Parameters panel.

- Click or tap a visible object in the main 3D viewport, or use the Selected object list. The toolbar exposes Move, Rotate, Scale, exact axis inputs, Fit selected object, Cancel and Apply. Drag a colored handle to edit, or drag the background to orbit. Move uses world axes, while Rotate and Scale use local axes. Object transforms pivot at each object's source origin.
- With focus in the viewport or on an editing button, use ⌘/Ctrl+C to copy an object, ⌘/Ctrl+V to paste, and ⌘/Ctrl+Z to undo a saved object edit. ⌘/Ctrl+Shift+Z or Ctrl+Y redo it. Text inputs and other workspace areas keep their normal shortcuts. Copy and paste stay within the project. Apply validates and saves staged moves and copies as a new revision.
- Toggle Parameters independently of selection. The panel floats to the right in wider editors and below the canvas in narrower editors. Escape or Close returns focus to the toggle. Closing the panel retains drafts and interrupted updates. The parameter Apply, Reset and Discard actions retain their existing behavior.
- The validated composition remains visible while object meshes load. Selecting an object shows the separately rendered operands in the same scene. For difference and intersection, the operand view shows what is being edited and the accepted boolean result is visible with selection cleared. When direct preview hits its geometry budget or cannot render an operand, the exact fields still work against the saved revision. Downloads remain bound to the accepted composition.
